# Stage3：風と自機狙いの放物弾

## 遊ぶ

Battleシーンの `DebuggerObject` で Stage 3 / Way / Start Phase Index 0 を選び、Playします。
左上の `WIND` 表示は「↑ 上風」「↓ 下風」「← 左風」「・ 無風」です。

風は入力に加算される移動です。無操作でも、その時点の移動速度の20%で押されます。
上風では上入力が1.2倍、下入力が0.8倍。低速移動中は、低速時の速度を基準に20%を計算します。
画面端の移動制限は従来どおりです。

## 放物弾の調整

Prefab：`Assets/Project/Scenes/Battle/Prefabs/Stage3/3_Bullet_WindAimed.prefab`

Inspectorの `Movement Steps > Accelerated Movement Config > Aimed parabola` で変更します。

| 項目 | 初期値 | 意味 |
|---|---:|---|
| Aim At Player | ON | 発射時の自機位置を狙う |
| Use Battle Wind | ON | 発射時の風を加速度の向きにする。無風では自機狙いの直線 |
| Target Flight Time | 4.2秒 | 発射時の自機位置へ到達する時間。短いほど速い |
| Vertex Depth | 1.1 | 発射位置と狙点より風上側に折り返す距離 |
| Vertex Screen Margin | 0.35 | 頂点と画面端の余白。端に近い自機に対しては自動縮小 |

狙点は発射時に固定され、発射後に自機を追尾しません。飛行中に風向きが変わっても、その弾の加速度は変えません。
Aim At PlayerをONにしたときは、初速度と加速度の大きさを自動計算するため、従来のInitial SpeedやAccelerationは使用しません。
Use Battle WindをOFFにするとWorld Accelerationの上下左右いずれかの向きを使用します。

発射位置・狙点が画面内なら、折り返し点から狙点までの弾道を画面内に収めます。
画面外にいる敵から撃つなど、指定方向の放物線を画面内で作れない場合は自機狙いの直線へ退避します。
今回の敵は画面内に入ってから発射します。通しテストでこの退避は0件でした。

### 計算条件

2点だけでは放物線は一意に決まらないため、加速度の向き、頂点の深さ、到達時間を追加条件にしています。
風向きの軸をqとすると、`q(t) = qVertex + a/2 × (t - tVertex)^2`、その直交軸は等速です。
発射位置と狙点をこの式に入れ、初速度と加速度を求めます。左風では横向きに折り返す放物線になります。

## 風の切り替え

`Assets/Project/DataStore/Stage3/Way/Stage3Way.asset` の `Wind` を編集します。

- Enabled：風の有効・無効。他のステージは初期値OFF。
- Player Speed Ratio：押される速度の比率。初期値0.2。
- Intervals：DirectionとSecondsを順に設定。最後まで進むと先頭へ戻る。

初期設定は `無風4秒 → 上9秒 → 下7秒 → 無風3秒 → 左8秒 → 上6秒 → 無風4秒 → 下9秒 → 左6秒`。
フェーズをまたいで継続し、リトライでは先頭へ戻ります。ポーズ中は時間が進まず、道中終了時に風と表示を解除します。

## 4フェーズの構成

| フェーズ | 敵数 | 構成 |
|---|---:|---|
| 1 | 9 | 上下の折り返し、減速停止、通常弾を時間差で混ぜる導入 |
| 2 | 18 | 近いタイミングの上下出現、蛇行、停止射撃を組み合わせる混戦 |
| 3 | 9 | 上下の役割を入れ替え、通常弾の狙い撃ちを挟む |
| 4 | 9 | 中央の停止射撃から上下の折り返しと蛇行へ展開 |

敵Prefabは `3_Enemy_WindBlue`、`3_Enemy_WindPink`、`3_Enemy_CommonFan`。
新しい移動プリセットは `WindHookUpper`、`WindHookLower`、`WindWeave`。
各フェーズのClipsに設定したMovement Overrideで、同じ敵の移動を変えています。

予定発射数は、風弾の敵33体×3発＋通常扇形弾の敵12体×6発＝171発。前の構成114発の1.5倍です。
敵を撃破すれば実際の発射数は減ります。

## Unityの編集ツール

`Tools（ツール）> Stage 3 > Wind Workshop` を開けます。

- `Apply parameters ... only`：スライダーの値を自機狙い弾Prefabだけに保存。
- `Rebuild Stage 3 ...`：4フェーズ、生成済みの風弾・敵・移動プリセット、風スケジュールを初期構成で再構築。手動調整した同じアセットの値も置き換えるため、通常の微調整にはInspectorかApplyを使用。
- `Validate trajectories ...`：576通りの弾道と、風による速度・タイマー・リセット・敵数を検証。
- `Start movement playtest ...`：通常の移動入力で自機を動かして確認。射撃や無敵化はしません。StopまたはPlay終了で解除。

アセットの作成・保存はこのUnity編集UIから実行します。シーンは自動保存しません。
